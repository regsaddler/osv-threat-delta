# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability in OSV Threat
Delta. Use GitHub's private vulnerability reporting for this repository.

Include the affected version, operating system, reproduction steps, expected
behavior, and observed behavior. Do not include credentials, private lockfiles,
or proprietary source code.

## Scope

The scanner reports OSV advisories associated with exact versions in a
supported lockfile. It does **not** establish runtime reachability,
exploitability, containment, remediation, or the absence of vulnerabilities.
It never installs, removes, updates, quarantines, or deploys packages.
